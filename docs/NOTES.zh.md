# Canvas Quick Mindmap

把 Obsidian 画布当思维导图用：选中或正在编辑一个文本节点时——

| 按键 | 选中节点时 | 正在输入时 |
|---|---|---|
| `Tab` | 新建子节点（放在右边，自动连线，直接进入输入） | 新建同级节点（插在当前节点下面） |
| `Enter` | 编辑这个节点（光标在文字末尾） | 新建子节点 |
| `Shift+Enter` | — | 换行 |

选中节点后，节点右边和下面会出现两个圆形「+」按钮：右边加子节点，下面加同级节点（手机上也能用）。选中的是图片时，右上角还会多一个「复制图片」按钮（只在电脑上有，做法和 Image Copy and Reveal 一样：PNG / JPG 直接从文件读，WebP 等格式先转成 PNG）。命令面板里有「添加子节点 / 添加同级节点 / 整理导图布局」。

**节点大小跟随文字**（默认开）：导图里的节点（有连线的文本节点）在输入时、加节点时、整理时自动调整宽高——短词就是窄框，超过最大宽度（默认 320）换行变高。空节点保持 120 宽方便输入。含图片、代码块、表格、标题的节点不动。测量用的是画布里一个隐藏的节点副本，主题的字体和内边距都会生效。

**搜索**：在画布里按 `⌘F`（正在输入时也行），或点右侧工具栏的放大镜。搜索文本节点、分组标题、链接、文件名，以及画布里嵌入的笔记内容；多个词用空格分开（都要命中）。命中的节点高亮、其余变淡，`Enter` / `Shift+Enter` 上下跳，`Esc` 关闭并选中当前结果（接着按 `Enter` 就能编辑）。`⌘F` 原本属于「在当前文件中查找」，它的快捷键比插件的监听先触发，所以注册在画布视图自己的 scope 上。

**整理**：画布右侧工具栏（缩放按钮下面）有一个「整理导图」按钮，命令面板里也有。它会把画布上每一棵树重新排好、所有连线改成「父节点右边 → 子节点左边」、把重叠的树上下错开，压在树上的散落节点（没连线的）挪到下面。一次撤销就能全部还原。

为什么默认水平间距是 160：Obsidian 的连线是贝塞尔曲线，控制点伸出的长度是两端距离的一半，限制在 70~150 像素之间。横向距离比这个短，曲线就会往回绕，兄弟节点一多看起来像打结。

设置：自动排版（默认开，整棵树重新排，节点不重叠）、编辑时 Enter 是否新建同级、水平 / 垂直间距。

另外，粘贴或拖进画布的图片等附件会按画布名重命名（`导图.png`、`导图-1.png`…），和 Paste Image Rename 在笔记里的效果一样（它本身只认 Markdown 笔记，在画布里会报「No active file found」）。只处理画布 5 秒内真的用上的文件；文本节点里的 `![[…]]` 链接会一起改掉（Obsidian 不会自动更新画布文本节点里的链接）。

## 实现要点

- 画布没有公开 API，用到的内部方法（`createTextNode`、`importData`、`menu.render` 等）对照 Obsidian 1.14.4 的 app.js 核实过。
- 画布里的编辑器在 iframe 里，窗口上的 keydown 收不到，所以编辑态的按键走 CodeMirror 扩展（`registerEditorExtension`），选中态走 window 捕获监听。中文输入法组字时（`isComposing`）不拦截 Enter。
- 新节点要先 `attach()` + `render()` 才有编辑器，否则 `startEditing()` 无效。
